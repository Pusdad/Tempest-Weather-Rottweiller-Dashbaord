⛈️ Connect to your Tempest

This dashboard reads your station data straight from the WeatherFlow API. It needs a free Personal Access Token:

  1. Sign in at tempestwx.com/settings/tokens
  2. Click Create Token, give it a name (e.g. "Dashboard")
  3. Copy the token and paste it below

The token is stored only in this browser (localStorage). It never leaves your machine except to call the WeatherFlow API directly.
